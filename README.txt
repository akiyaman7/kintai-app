勤怠管理システム

■ システムの説明

ブラウザだけで動作する勤怠管理ツールです。index.html 1ファイルのみで完結しており、
追加のインストールやサーバーは不要です。

・出勤、退勤、休憩、戻りの打刻
・当月の勤怠一覧（日付、申請、作業場所、勤務区分、開始、終了、休憩、労働時間、
  時間外、法定外残業、深夜、メモ）
・当月累計時間、時間外(残業)、有給残日数などの集計カード
・入力したデータはブラウザのlocalStorageに保存されるため、ブラウザを閉じても
  消えません（同じブラウザ・同じパソコンで開いた場合のみ有効です。別のパソコンや
  ブラウザでは共有されません）
・氏名、部署欄は初期状態でサンプルの名前が入っています。実在する氏名や社外秘の
  情報は入力しないようご注意ください

[労働時間の計算について]
・所定労働時間: 7.5時間/日（会社の基準として仮に設定）
・法定労働時間: 8時間/日（労働基準法の基準）
・時間外 = 労働時間が7.5時間を超えた分
・法定外残業 = 労働時間が8時間を超えた分（25%割増の対象になる時間の目安）
・深夜 = 22:00〜翌5:00にかかった時間

これらはあくまで目安の簡易計算です。実際の給与計算には使用しないでください。


■ システムの使い方

[1. 開き方]
index.html をダブルクリックすると、既定のブラウザで開きます。

[2. 画面右上]
・「‹ ›」で表示する月を切り替えられます
・「氏名」「部署」欄はクリックして直接書き換えられます
・歯車アイコン（⚙）で「当月の基準労働時間」「月の残業上限」を変更できます

[3. 打刻ボタン]
出勤  : 本日の「開始」に現在時刻を記録します
退勤  : 本日の「終了」に現在時刻を記録します
休憩  : 休憩開始時刻を記録します（再度休憩を開始しようとすると警告が出ます）
戻り  : 休憩終了時刻を記録し、休憩時間を自動で積み上げます
直行  : 本日の作業場所を「直行」にします。まだ出勤していなければ合わせて
        出勤も記録します
直帰  : 本日の作業場所を「直帰」にします。まだ退勤していなければ合わせて
        退勤も記録します

同じボタンをもう一度押すと、上書きしてよいか確認が表示されます。

[4. 勤怠実績明細（一覧表）]
・通常は読み取り専用の表示です
・各行右端の「✎ 編集」を押すと、その日の開始、終了、休憩、作業場所、勤務区分、
  メモなどを入力できる状態に切り替わります
・編集後、入力欄から離れると自動的に保存されます
・「✓ 完了」を押すと編集状態を終了し、通常表示に戻ります
・削除専用のボタンはありません。打刻ミスなどを取り消したい場合は、編集状態に
  して該当の時刻欄を空にしてください

[5. 有給残日数]
カード右の「✎」を押すと、残日数を直接入力できます。

[6. その他のボタン]
・「🖨 勤務表を出力」: 印刷画面を開きます
・「⬇ CSV出力」: 表示中の月の一覧をCSVファイルとしてダウンロードします
・「休暇・残業の申請」「📋 日報・勤怠MD」「📤 日報提出MD」「月次勤怠の申請を
  行う」などは、画面イメージに合わせて用意したボタンですが、現時点では実際の
  申請・連携機能はなく、押すと案内メッセージが表示されるだけの仮実装です

[7. データのリセットについて]
データはブラウザのlocalStorageに保存されています。削除したい場合は、
ブラウザの「サイトデータを削除」機能（このファイルを開いたサイト/ファイルの
データ）から消去してください。


■ Cloudflare PagesでのBasic認証について

functions/_middleware.js により、Cloudflare Pagesで公開したサイト全体に
Basic認証がかかるようにしています。ユーザー名・パスワードはコードに書かず、
Cloudflare側の環境変数から読み込みます。

[設定手順]
1. Cloudflareダッシュボード(https://dash.cloudflare.com)を開く
2. 「Workers & Pages」> 対象のPagesプロジェクトを選択
3. 「Settings」>「Environment variables」を開く
4. Production（必要であればPreviewも）に、以下の2つを追加する
   ・BASIC_AUTH_USERNAME : ログイン時のユーザー名
   ・BASIC_AUTH_PASSWORD : ログイン時のパスワード（「Encrypt」にチェックを
     入れてSecretとして保存することを推奨）
5. 保存後、デプロイを再実行する（環境変数の変更は次回以降のデプロイから
   反映されます。GitHubに何か変更をpushするか、ダッシュボードから
   「Retry deployment」を行ってください）

環境変数が未設定のままデプロイすると、サイトにアクセスした際に
「Basic認証の環境変数が設定されていません」というエラーが表示されます。
